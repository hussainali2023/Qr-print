✦ Simple 3-step flow

From QR scan to printed page in under 60 seconds

Only the shop owner has an account. Multiple customers scan and send at the same time.

01

Owner logs in

Sign in once on the PC connected to your printer. Launch Chrome with --kiosk-printing for 100% hands-free printing.

02

Customers scan & send

Multiple customers can scan the QR simultaneously and select multiple files at once.

03

Clean auto-print

Every file renders at 300 DPI without any headers, footers, or URL watermarks and prints immediately.

+

Live preview & wipe

Preview pages right on the station dashboard if needed. Once printed, files auto-delete for total privacy.

✦ For shop owners

Everything you need to run a smart print shop

Built for xerox centres, cyber cafes, campus copy shops and stationery stores.

01 — Multi-User

Simultaneous customers

5 or 10 customers can scan the poster and upload files at the exact same time without disconnecting each other.

02 — Multi-File

Batch file uploads

Customers can select multiple PDFs and images in one go and send them as a single batch.

03 — Clean Print

Zero header & footer

Prints the exact customer document with `@page { margin: 0 }` — no ticket banners, no URLs, no dates.

04 — Zero-Touch

Instant background print

Uses a hidden background print frame so the shop dashboard never redirects or freezes.

05 — Preview

Live document viewer

The shop owner can see thumbnail previews and inspect full pages of any incoming file on the dashboard.

06 — Privacy

Auto file cleanup

Files are wiped the instant printing finishes. Customers' documents never clutter your PC.
